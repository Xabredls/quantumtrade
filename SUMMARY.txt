📞 TROUBLESHOOTING
════════════════════════════════════════════════════════════════════════════════

Worker won't start?
  → Check: node --version (should be 22+)
  → Check: cat worker/.env | grep BINANCE
  → Run: npm install --legacy-peer-deps

Binance connection fails?
  → Test: curl https://testnet.binance.vision/api/v3/time
  → Check API keys in .env
  → Verify Tailscale is running

Dashboard can't reach worker?
  → Test: ping 100.85.216.9
  → Test: curl http://100.85.216.9:4000/health
  → Check WORKER_URL in .env

Gemini errors?
  → Check GEMINI_API_KEY format (starts with "AQ.")
  → Test API: curl -X POST https://generativelanguage.googleapis.com/...
  → Check rate limit (50/hour)
